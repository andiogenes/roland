# HR-16B samples go here

Put the Alesis HR-16B WAV files from <https://clustersound.com/product/freebies/hr-16b/> in this folder (sub-folders are
fine). `*.wav` files here are git-ignored: the pack is not part of this repository.

Check the pack's licence before you share a firmware image built with it.

    python3 overlay/tools/gen_hr16.py --list assets/hr16      # which file each lane would take
